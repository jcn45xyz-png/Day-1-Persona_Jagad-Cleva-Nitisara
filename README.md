Tugas TIK Mengajar Day 1

Deskripsi singkat mengenai repository.
sebuah wadah penyimpanan digital berbasis cloud di platform GitHub yang digunakan untuk menyimpan, mengelola, dan mengorganisasi berbagai aset proyek pengoperasian lunak seperti berkas kode program, dokumen konfigurasi, hingga media pendukung. Melalui repository ini, seluruh perubahan pada file proyek dapat tercatat secara rapi dan dapat diakses dengan mudah oleh para pengembang dari mana saja. Bahasa mudahnya repository atau repo seperti folder yang disimpan dalam cloud Github yang dapat diakses oleh para developer untuk mengakses konfigurasi, codingan, dll.

Tujuan atau kegunaan repository.
seUntukbagai media manajemen versi (version control) dan pusat kolaborasi proyek. Dengan adanya repository, setiap pembaruan atau perbaikan kode dapat dipantau riwayatnya (commit history), mencegah terjadinya masalah antar-file saat bekerja dalam tim, serta menjadi sarana dokumentasi resmi sekaligus portofolio digital yang aman dari risiko kehilangan data lokal.
